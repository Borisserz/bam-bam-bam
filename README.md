# ingest-parse

Скан накладной ТН-2 или ТТН-1 превращается в один Markdown-файл с текстом страниц. Команду запускать из папки проекта. Адреса Qwen и dots лежат в `scan.env`, в консоль их писать не нужно.

```powershell
uv sync
uv run ingest-parse накладная.pdf -o накладная.md --scan-layout --vision
```

Страница выравнивается. Heron находит блоки, линии бланка находят таблицу. Если в `scan.env` заполнен `SCAN_DOTS_URL`, dots добавляет свои рамки. Синяя ручка читается отдельным вырезом. Qwen по картинке пишет текст в `накладная.md`. Рядом появляется папка `media` со сканами страниц.

Подходят `.pdf`, `.jpg`, `.jpeg`, `.png`, `.tif`, `.tiff`, `.webp`, `.bmp`. Поворот из телефона применяется сам. Первый запуск может скачать веса раскладки.
