# ingest-parse

Скан белорусской накладной ТН-2 или ТТН-1. Команды запускать из папки проекта. Адреса Qwen и dots лежат в `scan.env`, в консоль их писать не нужно.

Полный текст накладной, как на скане, одним Markdown-файлом:

```powershell
uv run ingest-parse накладная.pdf -o накладная.md --scan-layout --vision
```

Сначала страница выравнивается. Heron находит блоки, линии бланка находят таблицу, dots добавляет свои рамки, если в `scan.env` заполнен `SCAN_DOTS_URL`. Синяя ручка читается отдельным вырезом. Qwen по этим вырезам пишет текст. Без `SCAN_DOTS_URL` остаются Heron, линии и ручка.

Поля бланка: грузоотправитель, грузополучатель, товарные строки, итог. Рядом с JSON лежит короткий Markdown:

```powershell
uv run ingest-ttn накладная.pdf -o out_ttn
```

На выходе `out_ttn\накладная.ttn.json` и `out_ttn\накладная.ttn.md`. Папка с PDF тоже подходит: разберутся все файлы внутри. Тот же `scan.env`.
