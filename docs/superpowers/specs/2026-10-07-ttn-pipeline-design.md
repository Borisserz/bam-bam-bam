# ТН-2 / ТТН-1 (Беларусь): скан PDF → JSON + Markdown для проверки

## Цель

Максимально точное извлечение полей накладных из сложных сканов (наклон, перевёрнутые
страницы, тусклая печать, мелкий шрифт) на Windows: своя VLM в LAN + Heron.
Команда: `uv run ingest-ttn <файл.pdf | папка> -o out\ttn`.

## Конвейер (на страницу)

1. **Растр** (`ttn/raster.py`, pypdfium2): dpi = родное разрешение встроенной картинки скана,
   в пределах 300–450; цифровой PDF — 300 dpi + текстовый слой как подсказка для VLM.
2. **Предобработка** (`ttn/preprocess.py`, OpenCV): оттенки серого → поворот 90°
   (профили проекций) → наклон (линии бланка, Hough; запасной путь — перебор углов по профилю)
   → выравнивание освещения (деление на фон) → мягкий CLAHE → лёгкий шумодав.
   Без бинаризации. Поворот 180°: Heron на 0° и 180°, берётся более уверенный.
3. **Зоны** (`ttn/zones.py`): Heron на выровненной странице; самая большая `table` — товарный
   раздел; выше — шапка, ниже — итоги/подписи. Строки таблицы — по горизонтальным линиям
   (морфология OpenCV). Таблица режется на куски по ≤ 10 строк, к каждому куску сверху
   приклеивается шапка таблицы. Нет таблицы у Heron → полосы с перекрытием.
4. **VLM** (`ttn/prompts.py`, `ttn/extract.py`), temperature 0, ответ — JSON:
   - шапка: вид бланка, серия, номер, дата, УНП и реквизиты сторон, основание, пункты, авто;
   - товарные строки по кускам (как написано, ничего не вычислять);
   - итоги и суммы прописью; подписи.
5. **Проверки** (`ttn/validate.py`): УНП — 9 цифр; серия — 2 буквы, номер — 7 цифр; дата;
   количество × цена = стоимость; стоимость × ставка = НДС; стоимость + НДС = с НДС;
   сумма строк = «Итого»; «Итого» = суммы прописью (`ttn/words.py`).
6. **Ремонт**: строка не сошлась → её вырез (с шапкой таблицы, крупнее) + текст ошибки → VLM,
   до 2 раз; принимается только ответ, который проходит проверку. То же для итогов.
7. **Склейка страниц**: шапка — с первой страницы, где поле есть; строки — подряд, без дублей
   по номеру строки; оборот ТТН (раздел II) не смешивается с товарами.
8. **Выход**: `<имя>.ttn.json`, `<имя>.ttn.md` (поля, товары, итоги, ✓/✗ по проверкам,
   ссылки на картинки), `debug/` (выровненная страница, зоны, куски).
   Кэш ответов VLM в `.vision-cache` — повторный прогон бесплатный.

## Поля

Общие: `form` (ТН-2 | ТТН-1), `series`, `number`, `date`, `shipper`, `consignee`
(`name`, `unp`, `address`), `basis`, `loading_point`, `unloading_point`, `released_by`,
`handed_by`, `accepted_by`, `power_of_attorney`, `seal`.
ТТН-1: `carrier_customer`, `vehicle`, `trailer`, `waybill`, `driver`.
Строка: `n`, `name`, `unit`, `quantity`, `price`, `cost`, `vat_rate`, `vat`, `cost_with_vat`,
`places`, `mass`, `note`. Итоги: те же числовые + прописью `vat_words`, `cost_with_vat_words`,
`mass_words`, `places_words`.
Числа — строкой как на бланке и `Decimal` после разбора (`1 234,56`).

## Без VLM

`--no-vision`: растр, предобработка, зоны и куски в `debug/` — посмотреть, что уйдёт в модель.

## Тесты

Синтетический бланк (сетка, строки) + наклон/поворот → углы восстанавливаются; деление на
куски; разбор чисел и прописи; проверки; оркестрация с поддельной VLM (ремонт строки,
склейка страниц, кэш); CLI. Реальная VLM — только на рабочем ПК.
